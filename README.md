# 나만의 수어 사전 (My Sign Dictionary)

> **2026 전국민 AI 경진대회 출품작**  
> 농아인주간보호시설 현장에서 어르신들과의 따뜻한 소통을 위해, 한국어 문장을 **한국수어(KSL) 문법과 맥락에 맞는 수어 단어 조합**으로 변환하고 **어르신의 수어 동작을 역검색**할 수 있는 맞춤형 모바일 웹앱(PWA)

---

## 주요 기능

1. **2단계 AI 문맥 번역 & 동음이의어 검증 (`/api/translate`)**
   - 한국어 자연어 문장을 한국수어(KSL) 어순으로 분해하고, 다의어·동음이의어를 문맥에 맞게 선택합니다.
   - 예: `"추석 잘 보내세요"` → 물건을 발송하는 `'보내다'` 대신 명절·시간을 생활하며 보내는 **`[추석] → [잘] → [지내다]`** 수어로 변환 + 비수지 기호(표정·고개짓) 가이드 제공
2. **현장 맞춤형 1초 카드 뷰 & 어르신 화면 공유 모드**
   - 영상 로딩을 기다리지 않고 1초 만에 따라 할 수 있는 **수형 일러스트 + 1줄 핵심 동작 요약** 기본 노출
   - 카드를 터치하면 국립국어원 원본 수어 동영상(`.mp4`) 인라인 반복 재생
   - 상단 **`크게 보기`** 버튼으로 어르신과 스마트폰 화면을 함께 보며 소통 가능
3. **주간보호시설 5대 상황별 즐겨찾기 문장함**
   - `인사/안부`, `식사/간식`, `복약/건강`, `프로그램`, `귀가/송영` 5대 카테고리 프리셋 내장 및 `localStorage` 기반 나만의 문장 저장 (0.1초 즉시 열람)
4. **손동작 묘사로 찾는 '수어 역검색' (`/api/reverse-search`)**
   - 어르신이 표현하신 수어의 한국어 단어를 모를 때, 눈으로 본 **손 모양·신체 부위·움직임 태그**를 선택하거나 묘사해 뜻을 역추적

## 로컬 실행 방법

```bash
cd my-sign-dictionary
npm install
cp .env.example .env.local
# .env.local에 GEMINI_API_KEY 입력 (미입력 시에도 내장 규칙 분석기 및 로컬 수어 사전으로 100% 동작)
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## Vercel 무료 클라우드 배포 방법 (Phase 5)

1. GitHub 레포지토리에 `my-sign-dictionary` 프로젝트를 푸시합니다.
2. [Vercel](https://vercel.com)에서 **Add New Project** → 해당 GitHub 레포지토리를 가져옵니다.
3. **Environment Variables** 설정에 아래 환경변수를 등록합니다:
   - `GEMINI_API_KEY`: Google AI Studio에서 발급받은 Gemini API 키
   - `KSL_API_KEY` *(선택)*: 문화공공데이터광장 국립국어원 한국수어사전 오픈API 인증키
4. **Deploy** 버튼을 누르면 배포가 완료되며, 생성된 URL을 스마트폰(Safari / Chrome)에서 열고 **'홈 화면에 추가'**를 누르면 네이티브 앱(PWA)처럼 전체 화면으로 즉시 사용할 수 있습니다.
